# Ảnh gốc của FC

Bỏ ảnh gốc (độ phân giải cao nhất có) vào đúng thư mục, đặt tên theo nội dung, viết thường, nối bằng gạch ngang.

| Thư mục | Nội dung | Ví dụ tên file |
|---|---|---|
| `space/` | Không gian villa: mặt tiền, phòng ăn, cửa chớp, sân vườn, chi tiết kiến trúc | `facade-evening-1.jpg` |
| `dishes/` | Món ăn: ảnh hero, cận kết cấu, quy trình chế biến | `kinmedai-1.jpg`, `kinmedai-process-1.jpg` |
| `drinks/` | Đồ uống, rượu vang, welcome drink | `welcome-drink-1.jpg` |
| `team/` | Đội bếp, đội phục vụ, bàn tay đang làm | `chef-plating-1.jpg` |
| `sets/` | Ảnh chung của set menu: set lunch, set dinner, set valentine, afternoon tea (xem `sets/README.md`) | `sets/afternoon-tea/overview-1.jpg` |
| `events/` | Sự kiện, tiệc riêng, catering, dịp lễ | `bespoke-catering-1.jpg` |

Ảnh ở đây dùng cho bài đăng mạng xã hội và cho website FC sau này.
