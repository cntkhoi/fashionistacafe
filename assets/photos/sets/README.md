# Ảnh set menu

Mỗi set một thư mục. Tạo thêm thư mục mới cho set khác theo cùng kiểu tên (vd: `set-christmas/`, `set-tet/`).

| Thư mục | Nội dung |
|---|---|
| `set-lunch/` | Set trưa |
| `set-dinner/` | Set tối |
| `set-valentine/` | Set Valentine |
| `afternoon-tea/` | Afternoon tea |

Trong mỗi thư mục, đặt tên ảnh theo vai trò:
- `overview-1.jpg`: ảnh toàn bộ set trên bàn (ảnh hero)
- `course-<tên món>-1.jpg`: từng món trong set (vd: `course-kinmedai-1.jpg`)
- `detail-1.jpg`: cận chi tiết, bàn tay phục vụ, khoảnh khắc rót trà/rượu
